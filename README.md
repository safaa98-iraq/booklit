# 家計簿 · دفتر كاكيبو

دفتر ميزانية منزلية على الطريقة اليابانية (Kakeibo)، بواجهة عربية هادئة مستوحاة من الورق الياباني (واشي) والحبر (سومي).

## الفكرة

كاكيبو طريقة يابانية عمرها أكثر من قرن: تكتب بيدك كل ما تنفق، وتسأل نفسك أربعة أسئلة كل شهر:

1. كم لديك من المال؟
2. كم تريد أن تدّخر؟
3. كم تنفق؟
4. كيف تتحسّن؟

وتُقسَّم المصاريف إلى أربعة أقسام:

| القسم | 漢字 | أمثلة |
|---|---|---|
| الضروريات | 必要 | طعام، مواصلات، فواتير |
| الرغبات | 欲望 | مطاعم، تسوّق، ترفيه |
| الثقافة | 文化 | كتب، دورات، موسيقى |
| الطوارئ | 予想外 | تصليحات، هدايا، ما لم يكن في الحسبان |

## الميزات

- **حسابات مستخدمين** (تسجيل، دخول، خروج): لكل مستخدم دفتره الخاص، ولا يرى أحد دفتر غيره.
- **خطة الشهر**: الدخل، المصاريف الثابتة، هدف الادّخار، ونيّة الشهر — ويُحسب المتاح للإنفاق تلقائياً.
- **تدوين المصاريف**: إضافة، تعديل، حذف، مع ملاحظة اختيارية، وتصفية حسب القسم.
- **التعليقات**: لكل مصروف سلسلة تعليقات (خواطر) يمكن إضافتها وحذفها.
- **حلقة إنسو (円相)** تُظهر نسبة ما أُنفق من المتاح، وجدول أسبوعي حسب الأقسام.
- **تأمّل نهاية الشهر**: الأسئلة الأربعة مع الأرقام الفعلية، وحقلان للكتابة.
- **عرض السنة**: اثنا عشر شهراً بأسمائها اليابانية التقليدية (睦月، 如月…) مع المصروف والادّخار.
- **الإعدادات**: الاسم والبريد ورمز العملة، وحذف الحساب نهائياً.
- وضع ليلي تلقائي، وتصميم يعمل على الهاتف.

## التقنية

- Laravel 12 (PHP 8.2+)، صفحات Blade تُعرض من الخادم، بلا خطوة بناء للواجهة (ملف CSS واحد: `public/css/kakeibo.css`).
- قاعدة البيانات: SQLite محلياً، PostgreSQL أو MySQL في الإنتاج.
- الجداول: `users`، `months` (خطة وتأمّل كل شهر)، `entries` (المصاريف)، `comments` (التعليقات).

## التشغيل محلياً

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed     # --seed ينشئ دفتراً تجريبياً: demo@kakeibo.test / password
php artisan serve
```

ثم افتح http://localhost:8000

## الاختبارات

```bash
php artisan test
```

## النشر على Render

الملف `render.yaml` ينشئ خدمة ويب (Docker) وقاعدة PostgreSQL. اضبط `APP_URL` بعد النشر، واجعل `SEED_DEMO=true` إن أردت الدفتر التجريبي.
